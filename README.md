# archivos-olvidados
Un montón de notas sueltas, ideas inconclusas, correos que nunca envié y cosas que probablemente debería haber borrado.
Estos documentos son parte de un respaldo viejo que encontré en un disco duro externo. No sé si sirvan de algo, pero los subo por si a alguien le interesa.
Hay muchas cosas que escribí en diferentes momentos: apuntes de clases, correos, ideas para proyectos, y hasta pensamientos random. Algunas cosas están duplicadas o mal nombradas, pero no tuve tiempo de ordenar todo.
Si encuentras algo útil, genial.
> "El que busca, encuentra."
